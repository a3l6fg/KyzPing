# KyzPing
KyzPing est un outil de surveillance réseau en Python qui envoie un ping continu vers une adresse IP et affiche les résultats dans une console intégrée. Il fournit en temps réel les statistiques de latence (min, max, moyenne, jitter) ainsi qu'un historique des erreurs réseau, le tout dans une interface sombre sans fenêtre CMD.
